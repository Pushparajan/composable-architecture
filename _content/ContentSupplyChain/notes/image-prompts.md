# Image prompts: Content Supply Chain series

One portrait image per post (20 total). Each prompt is self-contained: paste it as-is into your image generator.

## How to use

- **Format:** portrait 4:5, 1080 x 1350 px, PNG. This matches the carousel slides. If your generator only offers 2:3 or 3:4, use that and crop to 4:5.
- **Shared negative prompt** (paste into the "negative prompt" field if your tool has one, otherwise append "Avoid: ..." to the prompt):

  `text, letters, words, numbers, captions, logos, brand marks, watermarks, UI screenshots, photorealistic faces, distorted hands, clutter, neon colors, glossy 3D render`

- **Why no text in the images:** image generators garble lettering. Generate clean artwork, then add the title in Canva, Figma or Photoshop if you want it.
- **No brand marks:** the prompts avoid Adobe logos and product UI on purpose. Keep it that way to stay clear of trademark issues.
- **Series consistency:** every prompt starts with the same style block. Keep it if you edit a prompt, so the set stays cohesive.
- **Using the images:** save each result as `<slug>.png` (the slug is listed under each prompt). That replaces the carousel-cover PNG used as the `image:` value in the post's front matter.

## Shared style block (already included in every prompt below)

> Flat editorial vector illustration with a subtle paper-grain texture. Warm beige background (#F0E9E1), deep navy (#004182) and slate grey-blue (#576879) as the main colors, with one small warm amber accent (#E8A33D) used only on the focal point. Clean geometric shapes, soft gentle shadows, generous empty space in the upper third, calm and professional mood. Any people are faceless simple silhouettes seen from behind. Portrait 4:5 composition, 1080x1350.
